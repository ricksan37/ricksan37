## Featured project

**[france_data_market](https://github.com/ricksan37/france_data_market)**: a dbt +
DuckDB pipeline on French data job listings (France Travail + SIRENE, local-LLM
skill extraction, CI on GitHub Actions). Finished, and still running every week.
Every modeling decision is backed by a measurement on real data, not a guess.

**[Live report](https://ricksan37.github.io/france_data_market/)**

Three things it shows:
- Offers leave fast: 78.7% of the 816 offers live on 5 October had left France
  Travail four weeks later
- Only 26% of listings disclose a salary, 8% when the employer is masked
- SQL is named in 47% of qualified listings, dbt in 11%, and no cloud dominates
