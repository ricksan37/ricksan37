# Sample slides

Seven slide types, each a standalone 1280×720 HTML file composed from this system's components.
They follow `references/layout.md`: one composition per content shape, no layout repeated twice
in a row, generous margins, one lead accent per slide.

| File | Type | Notes |
|------|------|-------|
| cover.html | Cover | Mono kickers top row, one Slate panel floated on the grid |
| rail-split.html | Signature composition | Left rail plus a 50/50 content and media split |
| section-divider.html | Section divider | Display word on a Slate panel, nothing else |
| stats.html | Stat row | Three figures, three accents, no chart |
| icon-grid.html | Icon grid | Four concept cards in their locked hues |
| chart.html | Chart | One chart, one idea, two supporting figures |
| table.html | Table | Mono numeric columns, one highlighted row |

Copy is written in French here because the brand source is French. Tone rules are in
`../readme.md` under Content fundamentals. No dash anywhere, kickers included. The only survivor is the numeric range (12–20px).
