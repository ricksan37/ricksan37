The left rail of the signature composition. Pair it with a 50/50 content and media split.

```jsx
<NavRail
  items={[{ label: "Palette" }, { label: "Type" }, { label: "Grid" }, { label: "Data" }]}
  activeIndex={1}
  cta={{ kicker: "brief", label: "Start a project" }}
/>
```

- Four cards. Hues are positional: 01 blue, 02 amber, 03 vermilion, 04 green. No wordmark sits above them.
- The violet CTA card is the only violet on the screen. Omit it rather than duplicating violet elsewhere.
