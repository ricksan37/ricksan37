Fully rounded pill button in three variants. Use for the main action on a screen.

```jsx
<Button variant="primary">Read the system</Button>
<Button variant="cta" arrow={false}>Book a slot</Button>
<Button variant="secondary" arrow={false}>Later</Button>
```

- Primary inverts from the light system: light pill, Void text, trailing arrow.
- `cta` is Ultra Violet and is the only violet allowed on the screen. One per view, for booking or submitting.
- Hover shifts the fill one tone step. No shadow, no glow, no scale on press.
