A saturated block for the one idea that must dominate. Loud on near-black, so ration it.

```jsx
<AccentCard tone="amber">
  <Display level="h2" style={{ color: "var(--void)" }}>+38% in four quarters</Display>
</AccentCard>
```

- One per screen, never two. Text on it is Void `#0B0C0F`, never Paper.
- Never violet, never full-bleed across a whole slide.
